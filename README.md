# Uzbekistan Trade Analysis

## Overview

This project examines Uzbekistan's international trade patterns, with a focus on exports, imports, major trading partners, and trade diversification. 

## Objectives

- Analyze Uzbekistan's export and import trends
- Identify major trading partners
- Examine changes in trade composition 
- Assess the degree of trade diversification
- Discuss implications for Uzbekistan's economic development

## Methodology 

The project will use publicly available economic and trade data to conduct descriptive stattistical analysis and creative visualizations.
